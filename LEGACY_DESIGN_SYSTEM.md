# LEGACY Design System v2

LEGACY is a real estate intelligence platform, not a CRM skin.

The interface should feel like a command center for property, market, buyer, contact, and outcome intelligence. Every visual choice should increase clarity, trust, and speed.

## Design Commandments

1. The map is always the hero.
2. Every score must explain itself.
3. Every click should teach the user something.
4. Information is layered, never dumped.
5. Premium whitespace beats more widgets.
6. Intelligence before automation.
7. Truth over assumptions.
8. Confidence is earned through evidence.
9. Every page answers: what happened, why, and what should I do next?
10. If it does not help close a deal, it does not belong.

## Visual Direction

Use deep navy, gunmetal, steel, silver, electric blue, and controlled crimson.

Avoid bright gold, lime green, Bootstrap defaults, and crowded SaaS dashboards.

The product should feel premium, minimal, immersive, and trustworthy.
